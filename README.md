## Descripción del sistema

Huellas Felices es una aplicación web destinada a facilitar la gestión de reservas, alojamientos y mascotas dentro de un hotel y guardería.

El sistema permitirá gestionar usuarios, registrar mascotas, consultar la disponibilidad de alojamientos, realizar y cancelar reservas de estadía, consultar el historial de reservas y visualizar comprobantes de confirmación.

También se prevé administrar el estado de los distintos alojamientos, como caniles estándar, suites VIP y espacios destinados a felinos, permitiendo indicar si se encuentran ocupados, disponibles o en proceso de desinfección.

En esta primera versión se desarrolló un prototipo navegable utilizando únicamente HTML5 y CSS, simulando las principales funcionalidades del sistema.

## Pantallas desarrolladas

### Inicio

Presenta el sistema de gestión Huellas Felices y permite acceder a las principales funcionalidades mediante un menú de navegación.

### Usuarios

Permite visualizar y gestionar de manera simulada la información correspondiente a los usuarios del sistema y sus mascotas.

### Solicitar Turno

Contiene un formulario para simular la solicitud de una reserva de estadía, indicando la información necesaria para alojar a la mascota.

### Confirmación

Simula la confirmación exitosa de una reserva y muestra un comprobante con la información correspondiente a la estadía.

### Turnos

Permite visualizar las reservas registradas y consultar su estado.

### Historial de Reservas

Presenta un listado simulado de reservas anteriores y futuras realizadas por los usuarios.
